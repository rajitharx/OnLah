# Operator logos

Add one logo per operator, using these filenames. The app shows the operator code as text until a file exists.

| Operator code | File | Operator |
|---|---|---|
| GAS | `go-ahead.svg` | Go-Ahead Singapore |
| SBST | `sbs-transit.svg` | SBS Transit |
| SMRT | `smrt.svg` | SMRT Buses |
| TIBS | `tower-transit.svg` | Tower Transit Singapore |

Use SVG if possible. The logo is shown at 16 px high.
